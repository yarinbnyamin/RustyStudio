# Prototype graveyard

## Studio Autopilot (B) — 2026-11-01
- **Kill reason:** it lost a direct A/B pick. The playtester preferred coding the game they ship
  over coding the studio that ships it.
- **What worked:** "your code runs every day" was visible in the day log, and the balance model
  (hours/morale, marketing/fans, price/buyers) had real traps and a sweet spot.
- **What failed:** at chapter 1 (variables only) the code can only tune numbers, not make decisions.
- **Next time:** try automation only after `if` and loops are taught, as a side system inside the
  studio rather than the core loop.
